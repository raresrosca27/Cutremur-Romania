# Seismograf România

Cutremure în România și în împrejurimi, în timp real — hartă live, listă filtrabilă, „Am simțit acest cutremur”, ghid de siguranță și istoric. Română / English.

Earthquakes in Romania and nearby, in real time — live map, filterable list, "I felt it" reports, safety guide and history. Romanian / English.

- Date live: [EMSC](https://www.emsc-csem.org) (rezervă: [USGS](https://earthquake.usgs.gov))
- Un singur fișier: `index.html`, fără build. Publicat cu GitHub Pages.

Nu este un sistem oficial de avertizare. Informații oficiale: [INFP](https://www.infp.ro), [IGSU / Fii pregătit](https://fiipregatit.ro).
